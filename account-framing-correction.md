## Why the correction matters

The unresolved question is therefore not whether Cursor must support cross-email linking. It is whether the advertised SuperGrok Heavy benefit has any supported path when the paid X/xAI identity uses a valid `.ru` email address, and whether the permanent-link warning can be navigated without consuming the entitlement on an unintended account.

This correction supersedes any earlier statement that access must work specifically on the existing non-`.ru` Cursor account. It does **not** prove that the `.ru` suffix is the backend trigger; Cursor has not confirmed the evaluated policy.

## Resolution test

Resolution requires a successful new-account or linking path using the unchanged paid identity and legacy email, followed by live confirmation that Grok Bot access is available. A support assurance without a working product result is not sufficient.
